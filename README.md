# Aquateka

Android-приложение для специалистов по ремонту: помогает учитывать визиты к клиентам и видеть их на карте.

## Возможности

- Создание, изменение, удаление клиентов и их визитов.
- Автоматическое определение адреса по координатам.
- Просмотр списка визитов по месяцам.
- Просмотр визитов на карте(с фильтрами).
- Поиск визитов по имени или телефону клиента или по координатам визита.
- Авто перенос(по кнопке) незавершенных визитов на текущий месяц.
- Гибкая система ручного переноса визитов.
- Экспорт/импорт визитов и клиентов в формате csv.
- Открытие приложения карт с активной точкой, при нажатии геопозиции.
- Возможность изменять цвет метки на карте.
- Возможность просмотра истории визитов по каждому клиента.

## Технологии

- Kotlin
- Android SDK
- Room
- Coroutines
- Yandex Maps
- Java 17

## Требования

- Android Studio
- JDK 17
- Android 8.0 (API 26) или новее
- API-ключ Яндекс Карт

## Сборка и запуск

1. Склонируйте репозиторий и откройте его в Android Studio.
2. Добавьте API-ключ в `local.properties` в корне проекта:

   ```properties
   MAP_API_KEY=ваш_ключ
   ```

3. Соберите и запустите приложение через Android Studio или выполните:

   ```bash
   ./gradlew assembleDebug
   ```

   В Windows используйте `gradlew.bat assembleDebug`.
